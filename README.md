# AI-Based Fake URL Detection System

## Objective

This project detects suspicious and fake URLs using Python and basic AI logic.

It helps users identify phishing websites before opening them.

---

## Features

* Detects suspicious URLs
* Identifies phishing patterns
* Alerts users about risky links
* Simple and beginner-friendly project

---

## Technologies Used

* Python
* Basic AI Logic
* String Matching
* Cybersecurity Concepts

---

## Example

Input:

https://amaz0n-login-security.xyz

Output:

Warning: Suspicious / Fake URL Detected
